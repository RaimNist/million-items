# Million Items

## Live demo

Приложение развернуто на Render:

https://million-items-9a6d.onrender.com/

Приложение для работы со списком из 1 000 000 элементов.

Можно искать элементы по ID, добавлять новые ID, выбирать элементы и менять порядок выбранных элементов перетаскиванием.

## Возможности

- список из 1 000 000 элементов;
- загрузка списка по мере прокрутки;
- поиск по ID;
- добавление новых ID;
- выбор и удаление выбранных элементов;
- изменение порядка выбранных элементов;
- работа перетаскивания после поиска;
- серверное API;
- тесты серверной части.

## Запуск

Нужен Node.js 24.

Установить зависимости:

```bash
npm ci
```

Запустить клиент и сервер:

```bash
npm run dev
```

Клиент по умолчанию доступен на:

```text
http://localhost:5173
```

Сервер:


## API

| Метод  | Путь                        | Назначение                            |
| ------ | --------------------------- | ------------------------------------- |
| GET    | `/health`                   | проверка сервера                      |
| GET    | `/api/items`                | получение элементов                   |
| POST   | `/api/items`                | добавление ID                         |
| GET    | `/api/selected-items`       | получение выбранных элементов         |
| POST   | `/api/selected-items`       | выбор элемента                        |
| DELETE | `/api/selected-items/:id`   | удаление выбранного элемента          |
| PATCH  | `/api/selected-items/order` | изменение порядка выбранных элементов |

## Как хранится список

Исходные ID находятся в пределах от `1` до `1 000 000`.

Массив из миллиона элементов заранее не создаётся. Отдельно хранятся добавленные ID и состояние выбранных элементов.

Список выдаётся частями. Для получения следующей части клиент передаёт курсор, полученный в предыдущем ответе.

## Очереди запросов

На сервере отдельно обрабатываются запросы к данным и запросы на создание новых ID.

Запросы на создание накапливаются и обрабатываются очередью. Повторные ожидающие запросы на создание одного и того же ID не добавляют отдельную операцию.
